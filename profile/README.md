More from the lab: [STOUT](https://github.com/Kohulan/Smiles-TO-iUpac-Translator) (SMILES to IUPAC names), [CIDER](https://github.com/Steinbeck-Lab/ChemIcal-DatasEt-comparatoR) (chemical dataset comparison), and [everything else](https://github.com/orgs/Steinbeck-Lab/repositories).

Built on [CDK](https://cdk.github.io), [RDKit](https://www.rdkit.org), [Open Babel](https://openbabel.org) and [OPSIN](https://github.com/dan2097/opsin), in Python, Java, C, PHP and TypeScript, shipped with Docker. The machines are drawn with [Anatomy](https://github.com/wheresryan22/anatomy).
